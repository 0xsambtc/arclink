# Arclink 官网 · 账号开通清单（给产品）

> 背景一句话：官网技术方案已定——静态站 + 免费云服务，**全套 $0/月，只有域名年费**。上线前需要开通下面几个账号/服务。按优先级排列，每项写清目的、步骤、需要交回给 samuel 的东西。
> ⚠️ 所有密钥类信息（App Secret、AccessKey、Webhook 地址）请走私聊/密码管理器交接，不要发群或邮件明文。

## 1. 域名（进行中，最高优先级）

- **目的**：官网地址 + 发通知邮件的发信域。
- **步骤**：建议 `.com` 优先（海外企业客户的信任惯性）；任意注册商均可购买；**买好后把域名的 DNS 服务器切换到 Cloudflare**（免费，Cloudflare 账号建好后操作，samuel 可代做）。
- **交回**：① 域名本身；② 确认它与公司阿里企业邮箱绑定的域名**是否同一个**（影响 DNS 配置方式，两种都行）。
- **费用**：约 $10–15/年。

## 2. Cloudflare 账号（网站托管，尽快）

- **目的**：网站托管 + 表单处理 + 防垃圾验证 + 访问统计，全在这一家，免费版即可且允许商用。
- **步骤**：cloudflare.com 用公司邮箱注册（免费，5 分钟），开启两步验证；然后把 samuel 加为成员（Manage Account → Members），或直接交接登录方式。
- **交回**：账号可用 + samuel 有权限。
- **费用**：$0。
- 备注：注册后的技术配置（站点接入、AI 爬虫放行等）samuel 来做，产品不用管。

## 3. 阿里云 + 邮件推送 DirectMail（发邮件提醒用）

- **目的**：官网表单有人提交时，给公司邮箱发提醒邮件。选阿里云是因为公司邮箱就是阿里企业邮箱，同生态送达最稳。
- **步骤**：① 先确认公司管理阿里企业邮箱的阿里账号在哪个体系（国内站 aliyun.com / 国际站 alibabacloud.com），沿用同一体系；没有就注册 + 完成企业实名认证；② 在控制台开通"**邮件推送（DirectMail）**"服务（开通本身免费）。
- **交回**：账号可用 + samuel 有权限（后续发信域名验证、AccessKey 由 samuel 处理）。
- **费用**：每天 200 封内免费，超出约 ¥2/1000 封——官网通知量级下一年几块钱。

## 4. 飞书（存表单数据 + 群提醒）

- **目的**：官网收到的需求方咨询、采集人员报名，直接存进飞书多维表格（团队在里面筛选跟进，不用另建系统）；同时进一个飞书群做即时提醒。
- **步骤**：
  1. 建一个**多维表格**（放公司空间，命名如"官网线索"，先建空的即可，字段 samuel 来定）；
  2. [飞书开放平台](https://open.feishu.cn) 创建一个**企业自建应用**（命名如"官网表单"），在权限里开通**多维表格的读写权限**，发布启用；
  3. 建一个群（如"官网线索通知"），群设置里添加**自定义机器人**。
- **交回**：① 自建应用的 App ID + App Secret（私聊交接）；② 多维表格链接（并给自建应用授权访问）；③ 群机器人的 Webhook 地址（私聊交接）。
- **费用**：$0。

## 5. 顺手收集（官网内容要用）

- 公司**法定英文名称**与**新加坡注册地址**（页脚与结构化数据用，给海外客户看的合规信息）；
- **Logo 源文件**（矢量格式最好）；
- **已覆盖/可执行的城市清单**（先给 10 个也行，首页地球动画要标真实覆盖点）。

## 不需要产品做的（samuel 侧处理，仅知悉）

GitHub 代码仓库、Cloudflare 站点技术配置（Turnstile 人机验证、AI 搜索爬虫放行）、DNS 解析记录、Google/Bing 站长平台、可用性监控。

---

**时间关系**：第 2、4 项决定开发何时能接真实服务，越早越好；第 1、3 项在上线前一周到位即可；第 5 项随时。全部就绪后，从开发完成到正式上线约半天。
