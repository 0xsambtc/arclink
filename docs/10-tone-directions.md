## 二、三案共同骨架（无论选哪个都执行的"宪法"）

1. **字体宪法**：凡是"事实"（数字/坐标/时间戳/编号）必须 mono + tabular-nums；凡是"陈述"用 Inter。两极字阶（巨字 × 小标签），中间字号原则上不存在；
2. **三图元宪法**：点 = 节点城市，弧 = 一次真实采集交付事件，hex/刻度 = 覆盖单元——各锁死一个业务含义，全站不出现第四种图元；
3. **Proof of life**：任何图形元素 hover 必出真实记录卡（城市/km/UTC 时间戳）——GitHub globe 原话"没有它就只是设计动画"；
4. **弧场生成器**：stripe.dev 式参数化函数，真实数据做种子，全站图形同源同族（404/OG 图/行业配图都由它出）；
5. **诚实的数据**：一切"实时感"降级为构建时注入 + `AS OF` 日期标注；宁可 12 条真实记录轮播，不做 1000 条假弧线；
6. **性能硬指标**：LCP<1.5s、CLS<0.05、<3MB、60fps、FPS 分档降级、移动端静态 SVG 兜底、reduced-motion 全静态；
7. **得分策略**：Design+Usability=70% 权重打满（静态站天然优势），Creativity 靠系统性与版图空位上探，目标 HM 稳拿、SOTD 冲 7.2+。

## 三、三案概要

### 甲 · 勘测年鉴（The Field Atlas）
**宣言**：页面上任何元素，要么是排版系统本身（字/网格/编号/细线），要么是带真实出处的编号图版（FIG.）——两者都不是，删。
**形态**：官网 = Arclink 年度出版的外业勘测年鉴。Section = 章节（`SEC.03 / COVERAGE` running header + 右下角 folio 页码）；图形都是带图框和 caption 的 FIG. 图版。**全站唯一浅色 section"图版页"**（白纸质感 + 藏青字 + 平面点阵世界地图）是节奏最强记忆点。
**Signature**：① 会归档的封面——巨字标 + 活体 globe，滚动后整体收进图框变成 FIG.01；② 图版页（占领"平面数据地图无 SOTD"空位）。
**最大风险**：排版功力不达标全盘崩（无 3D 无素材遮丑）；克制被打成"寡淡"，Creativity 有天花板。

### 乙 · 地面站（Ground Station）
**宣言**：任何元素上屏前问一句——它是读数还是装饰？能标出单位/坐标/时间戳/数据来源的留下，答不上来的删。
**形态**：官网 = 监控 Arclink 网络的地面控制台。Section = 仪器模块（`MOD-03 / COVERAGE ─── ● LIVE` 面板头）；页缘 ruler 刻度列随滚动显示"深度"；十字准星光标；数字用里程表式逐位跳变；密（数据面板）疏（大字幕间）严格交替。
**Signature**：① 开机序列 hero——刻度 draw-in → mono 状态行 type-on → globe 升起逐城 plot + log 流同步追加；② 可操作覆盖台——采购方自己选城市/区域，地图弧线重排、读数刷新。
**最大风险**：离 admin 模板感一步之遥（模板感=取消资格）；全 mono 指令语气可能过冷（"黑客工具"而非"可签约伙伴"）。

### 丙 · 弧场（Arcfield）
**宣言**：站上每一个非文字图形都必须能追溯为"同一台生成器 + 一条真实覆盖数据"——任一答不上来，删。
**形态**：把真实覆盖数据喂给唯一的生成图形系统（弧族/点阵/等值线），"数据长成的图形"是全站唯一视觉语言，纯度最高。
**Signature**：生成器本身（stripe.dev /art 式可玩页面）。
**最大风险**：抽象度最高——对采购方可能读作"漂亮但说不清你们干什么"；对数据量依赖最深。

## 四、对比与裁决建议

| 维度 | 甲·年鉴 | 乙·地面站 | 丙·弧场 |
|---|---|---|---|
| 企业采购信任感 | ★★★★★（档案=严谨） | ★★★★（严谨但偏冷） | ★★★（偏抽象） |
| 拿奖上探空间 | ★★★★（空位+双 signature） | ★★★★★（signature 最强） | ★★★★（Creativity 纯度高） |
| 模板感/取消资格风险 | 低 | **中高（需严防）** | 低 |
| 工程可行（一人+Astro/GSAP） | ★★★★★ | ★★★★ | ★★★★ |
| 对数据量的依赖 | 中 | 中高 | 高 |
| 与品牌资产契合（弧+藏青） | ★★★★★（图版页呼应 logo 藏青） | ★★★★ | ★★★★★（弧即 logo） |

**裁决建议（Claude，待 samuel 确认）**：**主调 = 甲·勘测年鉴，吸收乙的两个 signature 交互**（开机序列并入"会归档的封面"编排、可操作覆盖台放进 Network CTA），**丙·弧场降格为三案共用的图形引擎**（它本来就是共同骨架第 4 条）。理由：年鉴给信任感和 Design 40% 最稳的地板且模板感风险最低；地面站的交互 signature 力度最强但整站冷感与模板风险高——取其交互、弃其整站语气；弧场作为完整调性最弱（抽象），作为引擎最强。

**M2 执行**：双变体对比升级为——**变体 A = 年鉴融合版**（甲骨架 + 乙 signature）vs **变体 B = 地面站纯版**（乙完整执行），共用宪法与图形引擎，实物对比投票定稿。
