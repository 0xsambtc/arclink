# 11 · 设计定版 v2 —「纸面年鉴 + 深色插页」（收束方案）

> 2026-08-04。综合三轮输入定版：获奖调研（docs/10）、评审尸检（scratchpad）、samuel 两轮 QA（十问题清单 + 第一性质询）。状态：🟡 待 samuel 审定后实施。本方案取代"三变体投票"——停止变体繁殖，收束为一个设计。

## 一、Review 结论（哪些站得住，哪些死）

**站得住（验证过的资产）**：信息架构（定位→数字→方法→覆盖→能力→行业→CTA 的采购动线）；mono=事实/Inter=陈述纪律；真实数据图形（字标弧线/覆盖图版/管线 trace）；NORTH PAPER 冷纸配色（色温同族+WCAG 实算达标）；12 列不对称网格与两极字阶；双语架构。

**死刑（samuel QA + 宪法审判）**：假种子生成图形（行业/能力的装饰弧线——名字哈希不是数据，违反自家宪法）；跨节归档飞行（脆弱炫技）；教程文案泄漏；全站印刷 chrome 过密（角线/套准/油墨条到处都是 = 概念说教）。

**第一性排序**：采购方 30 秒信任 > 拿奖；而调研本身证明两者同路——Design40%+Usability30% 奖励的就是纪律与手感，不是概念密度。

## 二、五条定案

### 定案 1 · 单一设计：冷纸为主，深色只做插页
生产版 = **NORTH PAPER 纸面年鉴**；全站唯一深色区 = 覆盖跨页插页（SEC.03）。理由：logo 原生适配（浅底设计）；赛道差异化（B2B 深色红海，浅色编辑部是获奖版图空位）；印刷隐喻在纸上自洽；"纸中一页深色数据插页"同时保留了深色科技感的记忆点。深色整站与 Station 变体封存 git 不删（`/m2/*` 保留作参照，生产不用）。

### 定案 2 · 图形宪法从严：站上只允许四种图形
① 字标图版（12 条真实交付弧线在 ARCLINK 字腔内）② 覆盖跨页（真实城市/弧线/读数/可操作台）③ 方法管线（一条真实事件的端到端 trace）④ 数字 specimen（真实指标 + 口径注脚）。**能力区与行业区不配图形**——排版立住。打样台（弧场生成器）迁独立彩蛋页 `/proof`，页脚 mono 链接进入（stripe.dev /art 模式），不占主线。

### 定案 3 · Chrome 减密（年鉴语言只留轻量层）
保留：SEC 编号 running header、FIG 图注（只跟真图形）、folio 页码、书脊轨（简化：竖排刊名 + 当前节 + 刻度点）、插页压页阴影与出血边。删除：全站四角裁切线（只留 SEC.03 插页四角）、套准十字、油墨条、每节重复的 EDITION 字样。

### 定案 4 · 动效系统（专业性的表达面）
大动效每节一个主角、绝不叠加：hero 开机序列（打字→巨字升起→字腔弧线描画→节点生长→log 滚入）/ 原位归档盖章 / 数字 count-up（tabular-nums 零抖动）/ 管线随滚动描画 / 覆盖台切区重放+巨数滚动。微交互层：按钮位移+发光、行提亮、图元 200ms 读出、focus 环。工艺铁律：60fps 只动 transform/opacity；入场动词分化（文字 clip 升、图框先线后内容、数字后滚）；缓动统一 power2/3/expo；reduced-motion 全静态。**每个动效过一道检验：它在演示什么能力（业务数据在流动 / 工程精度）。**
